1️⃣ 岩手県いわてけんの山やまで火事かじ　まだ火ひは消きえていない

山やまの火事かじのニュースです。
岩手県大槌いわてけんおおつち町ちょうにある山やまの2ふたつの場所ばしょで、22日にち、火事かじがありました。
県けんや自衛隊じえいたいなどのヘリコプターが空そらから水みずをまきましたが、まだ火ひは消きえていません。
町まちによると、23日にち午後ごご5時じまでに、200ヘクタールぐらいが焼やけました。家いえなど7ななつの建物たてものが焼やけました。
大槌町おおつちちょうは、20日はつかに起おこった大おおきい地震じしんのあと、国くにから特別とくべつな注意ちゅういの情報じょうほうが出でています。
町長ちょうちょうは「住すんでいる人ひとたちに、火事かじの情報じょうほうを知しらせます。そして地震じしんにも気きをつけるように言いいます」と話はなしています。

2️⃣ 宮城県みやぎけん塩釜市しおがましの保育園ほいくえん　地震じしんのときどうするか話はなし合あう

宮城県みやぎけん塩釜市しおがましにも、地震じしんについて国くにから特別とくべつな注意ちゅういの情報じょうほうが出でています。
塩釜市しおがましの「わだつみ保育園ほいくえん」では、先生せんせいたちが地震じしんのときどうするかを話はなし合あいました。
この中なかで、保育園ほいくえんの子こどもたちがどうやって避難ひなんする場所ばしょに行いけばよいか、かいた地図ちずを貼はってほしいという意見いけんがありました。今月こんげつ入はいった子こどもにも避難ひなんの練習れんしゅうをすぐにしてもらいたいという意見いけんも出でました。
保育園ほいくえんは、特別とくべつな情報じょうほうが出でている間あいだは、遠足えんそくなどをやめることにしました。

3️⃣ 株かぶの価格かかく　初はじめて6万まん円えんより高たかくなった

株かぶの価格かかくのニュースです。
東京株式市場とうきょうかぶしきしじょうで、23日にちの午前ごぜん、株かぶの価格かかくが初はじめて6万まん円えんより高たかくなりました。
株かぶの価格かかくは、株かぶを買かったり売うったりするときの値段ねだんです。去年きょねんの秋あきに5万まん円えんより高たかくなってから、半年はんとしで1万まん円えん高たかくなりました。アメリカとイランが日本にっぽん時間じかんの23日にちになっても戦たたかいを止とめていることなどが原因げんいんのようです。
しかし、そのあと株かぶの価格かかくが下さがりました。きょうの最後さいごの株かぶの価格かかくは、5万まん9000円えんぐらいでした。
イランの問題もんだいについての心配しんぱいが続つづいています。

4️⃣ 外国人がいこくじんを雇やとうとき県けんなどが外国がいこくの政府せいふと約束やくそくした「覚書おぼえがき」を作つくる

日本にっぽんで働はたらく外国人がいこくじんについてのニュースです。
東京とうきょうや東京とうきょうの周まわりの県けんでは外国人がいこくじんがたくさん働はたらいていますが、ほかの県けんでは、外国人がいこくじんを雇やとうことが難むずかしくなっています。
このため、県けんなどが外国がいこくの政府せいふとの約束やくそくを書かいた「覚書おぼえがき」を作つくることが増ふえています。その県けんなどで外国人がいこくじんに働はたらいてもらおうと考かんがえているからです。
NHKが調しらべると、北海道ほっかいどうと大阪府おおさかふと18の県けんが、ベトナムやインドネシア、インド、ネパールなどと、覚書おぼえがきを作つくっていました。
多おおくの県けんなどでは3年ねんぐらい前まえから、農業のうぎょうや観光かんこう、介護かいごなどの仕事しごとで外国人がいこくじんに働はたらいてもらうための覚書おぼえがきを作つくりました。安心あんしんして働はたらいたり生活せいかつしたりできるようにすることなどを約束やくそくしています。
