2️⃣ 熊本県氷川町くまもとけんひかわちょう　ボランティアが避難ひなんしている人ひとの健康けんこうをチェック

先週せんしゅうの大おおきい地震じしんで、熊本県くまもとけんでは、6700人にんぐらいが今いまも避難ひなんしています。
震度しんど7だった氷川町ひかわちょうでは、1200以上いじょうの家いえが壊こわれました。車くるまの中なかやテントに避難ひなんしている人ひともいます。
看護師かんごしなどのボランティアたちは、車くるまの中なかなどに避難ひなんしている人ひとが元気げんきかどうか、健康けんこうをチェックしています。
避難ひなんしている女性じょせいは「近所きんじょの家いえで風呂ふろに入はいっていますが、毎日まいにちは入はいることができません」と話はなしていました。
ボランティアは、壊こわれた家いえにある財布さいふや携帯電話けいたいでんわなどをさがす手伝てつだいもしています。
ボランティアの人ひとは「暑あつくて水道すいどうを使つかうこともできません。今度こんどの災害さいがいは大変たいへんです」と話はなしていました。

3️⃣ 広島ひろしまに原爆げんばくが落おとされてから81年ねん　平和へいわを祈いのる

8月がつ6日むいか、広島ひろしまに原爆げんばくが落おとされてから81年ねんになりました。
広島市ひろしましの公園こうえんで、5万まん人にんぐらいが出席しゅっせきして、平和へいわを祈いのる式しきがありました。原爆げんばくが落おとされた午前ごぜん8時じ15分ふんに、亡なくなった人ひとたちのためにみんなで祈いのりました。
広島市ひろしましの松井まつい市長しちょうは「たくさんの国くにが核兵器かくへいきの強つよい力ちからに頼たよっていて、核兵器かくへいきのない世界せかいにすることが難むずかしくなっています。私わたしたちは早はやく核兵器かくへいきがなくなることを願ねがっています」と言いいました。
広島市ひろしましの小学生しょうがくせい2人ふたりは「原爆げんばくの被害ひがいを受うけた人ひとから話はなしを聞きくことができるのは、私わたしたちぐらいの若わかい人ひとが最後さいごです。原爆げんばくのことを知しって、平和へいわのために行動こうどうすることが大切たいせつです」と言いいました。

この大会たいかいで、初はじめてのことが行おこなわれています。
5日いつかの開会かいかい式しきでは、愛媛県えひめけんの高校生こうこうせい2人ふたりが、大会たいかいに出でる学校がっこうの紹介しょうかいなどを、初はじめて手話しゅわで伝つたえました。
手話しゅわは、聞きこえない人ひとや聞きこえにくい人ひとなどが手てを動うごかして会話かいわをします。
そして、この大会たいかいでは、初はじめて女性じょせいが審判しんぱんをします。女性じょせいの審判しんぱんは全部ぜんぶで5人にんです。
5日いつかの試合しあいでは、埼玉県さいたまけんの森田もりた真紀まきさんが審判しんぱんをしました。体からだを大おおきく使つかって、アウトやセーフなどを決きめていました。
森田もりたさんは「緊張きんちょうしましたが、皆みなさんに助たすけてもらって無事ぶじに終おわりました」と話はなしていました。
