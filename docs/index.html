1️⃣ 気象庁きしょうちょう「エルニーニョ現象げんしょうが今いままででいちばん強つよい」

異常いじょうな天気てんきの原因げんいんになると考かんがえられている「エルニーニョ現象げんしょう」のニュースです。
エルニーニョ現象げんしょうは、ペルーの近ちかくの太平洋たいへいようで、海うみの温度おんどがいつもの年としより高たかくなる現象げんしょうです。今年ことしの10月がつは、いつもの年としより4.4℃高たかくなりました。4.4℃の差さは、今いままででいちばん大おおきくなっています。
気象庁きしょうちょうによると、この強つよいエルニーニョ現象げんしょうのため、今年ことしの冬ふゆは日本中にっぽんじゅうで暖あたたかくなりそうです。湿しめった空気くうきが日本にっぽんに入はいりやすいため、太平洋たいへいよう側がわなどで雨あめも多おおくなりそうです。
気象庁きしょうちょうの人ひとは「暖あたたかい日ひが多おおくても、冷つめたい空気くうきが入はいると急きゅうに雪ゆきがたくさん降ふるかもしれません。気きをつけてください」と言いっています。

2️⃣ 外国人がいこくじんの旅行者りょこうしゃ　1度消費税しょうひぜいを払はらってから返かえしてもらう

外国人がいこくじんの旅行者りょこうしゃが、買かい物ものをするとき、消費税しょうひぜいを1度ど払はらうことになりました。
日本にっぽんに旅行りょこうなどで来きた外国人がいこくじんは、今いままでは、店みせでパスポートなどを見みせると、消費税しょうひぜいを払はらわないで、買かい物ものができました。
11月がつ1日ついたちからは、買かい物ものをするときに1度ど消費税しょうひぜいを払はらいます。そして、日本にっぽんから帰かえるときに手続てつづきをして、クレジットカードなどで消費税しょうひぜいを返かえしてもらいます。
しかし、品物しなものを買かってから90日にちを過すぎると、返かえしてもらうことができません。

3️⃣ 千葉県ちばけんの印旛沼いんばぬま　稲いねなどに悪わるい水草みずくさが広ひろがる可能性かのうせい

先月せんげつの台風たいふうの大雨おおあめで千葉県ちばけんの印旛沼いんばぬまでは堤防ていぼうが壊こわれて、沼ぬまの水みずが外そとに出でました。この印旛沼いんばぬまから田たんぼの稲いねなどにとても悪わるい影響えいきょうがある水草みずくさが流ながれて外そとに広ひろがった可能性かのうせいがあります。
この水草みずくさは、南みなみアメリカから日本にっぽんに入はいってきた「ナガエツルノゲイトウ」で、とても強つよく育そだって田たんぼでもたくさん増ふえます。
そして、稲いねの成長せいちょうの邪魔じゃまをします。
国くにや県けんなどはこの水草みずくさを見みつけて、取とっています。
千葉県ちばけんでは、この水草みずくさを見みつけたら、スマートフォンのアプリで知しらせるように言いっています。

4️⃣ アメリカ　世界せかいでいちばん大おおきい「動物どうぶつのための橋はし」

アメリカのカリフォルニア州しゅうなどが、動物どうぶつのための橋はしを作つくっています。
カリフォルニア州しゅうでは、ピューマなどの動物どうぶつがいる場所ばしょに高速道路こうそくどうろがあります。動物どうぶつが車くるまとぶつかることなどが問題もんだいになっています。
このため、カリフォルニア州しゅうなどは、4年ねん前まえから、高速道路こうそくどうろの上うえに動物どうぶつたちが通とおる橋はしを作つくっています。
橋はしの長ながさは76m、幅はばは53mです。世界せかいでいちばん大おおきい動物どうぶつのための橋はしになります。橋はしには、動物どうぶつが通とおりやすいように、たくさんの植物しょくぶつを植うえています。
工事こうじは、今年ことし12月がつに終おわる予定よていです。
