青森県あおもりけんでは20歳さいぐらいの女おんなの人ひとが逃にげるときに足あしにけがをしました。
休やすみになった学校がっこうもあります。
青森県八戸市あおもりけんはちのへしでは、学校がっこうの食事しょくじを作つくる2ふたつの給食きゅうしょくセンターで建物たてものが少すこし壊こわれました。
食事しょくじを作つくることができないため、21日にちは八戸市はちのへし内ないの65の小学校しょうがっこうと中学校ちゅうがっこうが休やすみになりました。
