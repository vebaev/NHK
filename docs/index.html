1️⃣ 青森県あおもりけんなどで大おおきい地震じしんがありました

地震じしんと津波つなみのニュースです。
20日はつか午後ごご4時じ52分ふんごろ、青森県あおもりけんで大おおきい地震じしんがありました。
青森県あおもりけんで震度しんど5強きょうでした。

警察けいさつは、男おとこの子こが亡なくなったあと、父親ちちおやが調しらべていたと考かんがえています。

3️⃣ ローマ教皇きょうこう「乱暴らんぼうなリーダーたちが世界せかいを壊こわしている」

ローマ教皇きょうこうが、戦争せんそうをするリーダーたちを批判ひはんしました。
アフリカのカメルーンで16日にち、ローマ教皇きょうこうのレオ14世せいが話はなしをしました。
レオ14世せいは「乱暴らんぼうなリーダーたちが世界せかいを壊こわしている」と話はなしました。そして、壊こわすのは一瞬いっしゅんだが、直なおすには長ながい時間じかんがかかると言いいました。
ローマ教皇きょうこうについて、トランプ大統領だいとうりょうは「私わたしは教皇きょうこうを敵てきだと思おもっていない。イランは核兵器かくへいきを持もってはいけない。教皇きょうこうは、それを理解りかいしなければならない」と話はなしました。

4️⃣ 気温きおんが 40℃以上いじょうになった日ひは「酷暑こくしょ日び」

気象庁きしょうちょうは、気温きおんが40℃以上いじょうになった日ひを「酷暑こくしょ日び」と呼よぶことにしました。
25℃以上いじょうの日ひは「夏なつ日び」、30℃以上いじょうは「真夏日まなつび」、35℃以上いじょうは「猛暑日もうしょび」です。40℃以上いじょうの日ひには、名前なまえがありませんでした。
気象庁きしょうちょうは、40℃以上いじょうになる日ひが増ふえたため、名前なまえをつけることを考かんがえました。
ウェブサイトでアンケートをした結果けっか、「酷暑こくしょ日び」がいちばん多おおくなりました。ひどく暑あつい日ひという意味いみです。
酷暑こくしょ日びと聞きいたら、熱中症ねっちゅうしょうなどにならないように対策たいさくしてください。
