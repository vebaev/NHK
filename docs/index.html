1️⃣ 静岡県しずおかけんなどで40℃以上いじょうの「酷暑こくしょ日び」　41.1℃になった所ところも

23日にちも、とても暑あつくなりました。危険きけんな暑あつさが続つづいています。

静岡県浜松市しずおかけんはままつし佐久間さくまでは、41.1℃になりました。今年ことし、一番いちばん暑あつくなりました。

岐阜県ぎふけん、愛知県あいちけん、三重県みえけんでも40℃ど以上いじょうの「酷暑こくしょ日び」になった所ところがありました。

24日にじゅうよっかは、関東地方かんとうちほうから沖縄おきなわまでの30の県けんなどに、熱中症ねっちゅうしょうの危険きけんを知しらせる「熱中症ねっちゅうしょう警戒けいかいアラート」が出でています。

気象庁きしょうちょうによると、関東地方かんとうちほうと山梨県やまなしけん、長野県ながのけん、そして山形県やまがたけん、宮城県みやぎけん、福島県ふくしまけんでは、天気てんきが変かわりやすくなっています。

特とくに関東地方かんとうちほうでは23日にちの夜よる、急きゅうに強つよい雨あめが降ふりそうです。

低ひくいところに水みずが入はいったり川かわの水みずが増ふえたりするかもしれません。気きをつけてください。

2️⃣ 熱中症ねっちゅうしょうに気きをつけて　1週間しゅうかんで1万人まんにんが病院びょういんに運はこばれた

日本にっぽんのいろいろなところで熱中症ねっちゅうしょうになる人ひとが増ふえています。
総務省消防庁そうむしょうしょうぼうちょうによると、7月がつ19日にちまでの1週間しゅうかんに、熱中症ねっちゅうしょうで病院びょういんに運はこばれた人ひとは1万人まんにん以上いじょうでした。
前まえの週しゅうの2倍ばい以上いじょうで、すごく増ふえています。
病院びょういんに運はこばれた人ひとの中なかで、14人にんが亡なくなりました。6700人にんぐらいが65歳さい以上いじょうの人ひとでした。
エアコンを使つかって涼すずしくしてください。のどが乾かわいていなくても、水みずを飲のんでください。
外そとで仕事しごとをするときは、何回なんかいも休やすむようにしてください。

3️⃣ ウクライナ　文化財ぶんかざいを攻撃こうげきから守まもるカバーを取とる作業さぎょうが始はじまった

ロシアの攻撃こうげきが続つづいているウクライナのニュースです。
ウクライナでは、古ふるくて大切たいせつな、建物たてものや石いしの像ぞうなどの文化財ぶんかざいを、木きや鉄てつの板いたでカバーをしました。ロシアの攻撃こうげきから守まもるためです。
しかし、戦たたかいが長ながく続つづいて、板いたでカバーをした石いしの像ぞうの色いろなどが、温度おんどや湿度しつどで悪わるくなる心配しんぱいが出でてきました。
このためキーウ市しは、一部いちぶの文化財ぶんかざいのカバーを取とる作業さぎょうを始はじめました。
キーウ市しでは、今いままでに200以上いじょうの文化財ぶんかざいが、攻撃こうげきで壊こわれました。
市しは、カバーがあっても攻撃こうげきから守まもることは難むずかしいと考かんがえています。
そして、文化ぶんかや歴史れきしを知しってもらうために、文化財ぶんかざいを見みせることも大切たいせつだと考かんがえています。

4️⃣ 松江城まつえじょうの周まわりを回まわる船ふねに「風鈴ふうりん」　涼すずしく感かんじてほしい

島根県しまねけんの松江城まつえじょうでは、城しろの周まわりのお堀ほりを船ふねに乗のって楽たのしむことができます。
船ふねは、毎年まいとし夏なつに、涼すずしく感かんじてもらうために「風鈴ふうりん」をつけています。風鈴ふうりんは、風かぜが吹ふくときれいな音おとがなる鈴すずです。
今年ことしは、21日にちから始はじまりました。旅行りょこうに来きた人ひとたちは、風鈴ふうりんの音おとを聞ききながら、昔むかしの家いえが見みえる景色けしきを楽たのしんでいました。
岡山県おかやまけんの男性だんせいは「風鈴ふうりんの音おとを聞きいて夏なつが始はじまったと感かんじました」と話はなしていました。
この風鈴ふうりんの船ふねは、8月がつの終おわりまでの予定よていです。
