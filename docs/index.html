警察けいさつは、4し月がつ30日にち、北海道ほっかいどうの旭山あさひやま動物園どうぶつえんで働はたらく鈴木すずき達也たつや容疑者ようぎしゃを逮捕たいほしました。
亡なくなった妻つまの鈴木すずき由衣ゆいさんを動物園どうぶつえんに運はこんで焼やいた疑うたがいです。
鈴木すずき容疑者ようぎしゃは、逮捕たいほされる前まえに、亡なくなった妻つまを動物園どうぶつえんで焼やいたと話はなしているようです。
この事件じけんを調しらべている人ひとによると、動物園どうぶつえんで由衣ゆいさんの物ものかもしれないスマートフォンが見みつかっています。
警察けいさつによると、4し月がつ23日にち、由衣ゆいさんがいなくなったと家族かぞくから相談そうだんがありました。
由衣ゆいさんは「残のこらないよう燃もやしてやる」などと、夫おっとに言いわれたと、家族かぞくに話はなしていたようです。　
旭山あさひやま動物園どうぶつえんは休やすんでいましたが、1日ついたち、オープンしました。
