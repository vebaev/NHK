1️⃣ 熊本県くまもとけんや大分県おおいたけんなどでたくさん雨あめが降ふって被害ひがいが出でた

九州北部きゅうしゅうほくぶ地方ちほうでは、2日ふつか朝あさ早はやく、たくさん雨あめが降ふりました。
熊本県くまもとけんや大分県おおいたけんなどでは、「線状降水帯せんじょうこうすいたい」ができて、同おなじ所ところでたくさんの雨あめが降ふりました。
この雨あめで、被害ひがいが出でています。
熊本県くまもとけん小国町おぐにまちでは、川かわの水みずがあふれました。
川かわの近ちかくにある旅館りょかんは、建物たてものの中なかに川かわの水みずが入はいりました。雨あめで予約よやくのキャンセルがあって、旅館りょかんに客きゃくはいませんでした。
大分県日田市おおいたけんひたしでは、山やまが崩くずれた所ところが10以上いじょうありました。通とおることができない道みちがあるため、崩くずれた土つちや倒たおれた木きを片かたづけています。
九州地方きゅうしゅうちほうは、4日よっか、またたくさん雨あめが降ふるかもしれません。気象庁きしょうちょうは、新あたらしい情報じょうほうをチェックするように言いっています。

2️⃣ ベネズエラの地震じしん　亡なくなった人ひとが2000人にんより多おおくなった

ベネズエラで大おおきい地震じしんが起おこってから1週間しゅうかんになりました。この地震じしんで亡なくなった人ひとは、2295人にんになりました。
地震じしんの被害ひがいが大おおきい所ところでは、ベネズエラやほかの国くにの専門せんもんの人ひとたちが、壊こわれた建物たてものの中なかにいる人ひとを助たすけようとしています。
ラ・グアイラ州しゅうでは、地震じしんから6日むいかたって、3歳さいの男おとこの子こが生いきているのが見みつかりました。大おおきな声こえで喜よろこぶ人ひとや拍手はくしゅする人ひともいました。
国連こくれんによると、地震じしんから1週間しゅうかんになり、食たべ物ものや飲のむ水みずが足たりなくなっています。食たべ物ものや避難ひなんする場所ばしょを作つくることなどが必要ひつようになっています。

3️⃣ カブス鈴木すずき誠也せいや選手せんしゅ　大だいリーグで100本ぽんホームランを打うった

大だいリーグ、カブスの鈴木すずき誠也せいや選手せんしゅが、1日ついたちのパドレスとの試合しあいでホームランを打うちました。
大だいリーグで打うった100本ぽん目めのホームランです。
鈴木すずき選手せんしゅは、大だいリーグに入はいって5年ねんになります。
鈴木すずき選手せんしゅは「外国がいこくで野球やきゅうをするのは大変たいへんでした。チームの人ひとたちと、いい時ときも悪わるい時ときも一緒いっしょに、もっと良よくなろうと思おもってやってきました」と話はなしました。
大だいリーグでホームランを100本ぽん以上いじょう打うった日本にっぽんの選手せんしゅは、松井まつい秀喜ひできさん、イチローさん、大谷おおたに翔平しょうへい選手せんしゅ、そして鈴木すずき選手せんしゅの4人にんです。
ドジャースの大谷おおたに選手せんしゅは、今いままでに298本ほんのホームランを打うっています。300本ぽんまであと2本ほんです。

4️⃣ 岩手県いわてけん　海うみに入はいってウニをとる「海女あま」　観光かんこうに来きた人ひとに見みせる

岩手県久慈市いわてけんくじしで、「海女あま」と呼よばれる女性じょせいが、海うみの中なかに入はいってウニをとっています。
毎年まいとし7月がつ1日ついたちから、この海女あまの仕事しごとを観光かんこうに来きた人ひとに見みせています。1日ついたちは、4人にんの海女あまが海うみに入はいりました。
新あたらしく海女あまになった人ひともいて、とったウニを持もって海うみから顔かおを出だすと、見みていた人ひとたちは拍手はくしゅしました。
海女あまがとったウニは、観光かんこうに来きた人ひとがすぐに買かって食たべることができます。
ウニを食たべた男性だんせいは「海うみの塩しおの味あじがして、おいしかったです」と話はなしていました。
