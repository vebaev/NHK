1️⃣ 九州北部きゅうしゅうほくぶと中国地方ちゅうごくちほうと近畿地方きんきちほうで梅雨つゆが終おわった

8日ようかは、九州きゅうしゅうから北海道ほっかいどうまで多おおくの場所ばしょで、よく晴はれました。
気象庁きしょうちょうは「九州きゅうしゅうの北きたのほうと、中国地方ちゅうごくちほう、近畿地方きんきちほうで梅雨つゆが終おわったようだ」と言いいました。いつもの年としより11日にち早はやいと言いっています。
そして、8日ようかはとても暑あつくなりました。
福岡県ふくおかけんなどで気温きおんが35℃以上いじょうになった所ところがありました。東京とうきょうも30℃以上いじょうになりました。
気象庁きしょうちょうによると、このあとも暑あつい日ひが続つづきそうです。
熱中症ねっちゅうしょうにならないように、エアコンを使つかって部屋へやを28℃以下いかにしてください。暑あつい日ひは、喉のどがかわいていなくても少すこしずつ水みずを飲のむようにしてください。

2️⃣ 飲のみ物ものの会社かいしゃ「アサヒ」　利益りえきは36.7%少すくなくなった

ビールなどの飲のみ物ものの会社かいしゃ「アサヒグループホールディングス」は、去年きょねんサイバー攻撃こうげきを受うけました。
コンピューターのシステムが動うごかなくなって、工場こうじょうで作つくった品物しなものを店みせなどに出だすことができなくなりました。前まえのように品物しなものを出だすまでに4か月げつ以上いじょうかかりました。
会社かいしゃは、去年きょねん品物しなものを売うって入はいったお金かねなどを、5か月げつ遅おくれて7月がつ8日ようかに発表はっぴょうしました。
利益りえきは、前まえの年としに比くらべて36.7%少すくなくなりました。
会社かいしゃは、システムを直なおすためなどに、たくさんのお金かねがかかったと言いっています。

3️⃣ 東京都とうきょうと　銃じゅうを使つかって熊くまを捕つかまえることを考かんがえている

東京とうきょうでも山やまなどで熊くまの被害ひがいが続つづいています。
7日なのか檜原ひのはら村むらで、熊くまにあった人ひとが道みちから10ｍ下したに落おちてけがをしました。
ことし5月がつには奥多摩町おくたままちで、山やまに登のぼっていた人ひとが熊くまに襲おそわれてけがをしました。
東京都とうきょうとは、20年ねんぐらい前まえからツキノワグマを捕つかまえることをルールで禁止きんししています。
しかし、熊くまの被害ひがいをなくすためにルールを変かえることを考かんがえています。
銃じゅうを使つかって熊くまを捕つかまえることができるようにしたいと考かんがえています。

4️⃣ 北海道ほっかいどう函館市はこだてし　七夕たなばたの行事ぎょうじ「ろうそくもらい」があった

7月がつ7日なのかは七夕たなばたでした。
北海道ほっかいどうの函館市はこだてしで「ろうそくもらい」という昔むかしから続つづいている行事ぎょうじがありました。
浴衣ゆかたを着きた子こどもたちが家いえを回まわって、昔むかしはお祭まつりなどで使つかうろうそくをもらっていました。
今いまは、ろうそくの代かわりにお菓子かしをもらいます。この行事ぎょうじは100年ねん以上いじょう続つづいています。
子こどもたちは「ろうそく1本ぽんちょうだいな」と元気げんきよく歌うたってお菓子かしをもらっていました。
男おとこの子こは「友達ともだちと一緒いっしょに回まわるので楽たのしいです。いちばんうれしかったのはドーナツです」と話はなしていました。
