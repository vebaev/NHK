熊本くまもとの地震じしんから、6日むいかが過すぎました。
危険きけんな暑あつさが続つづいています。熊本市くまもとしでは、40.3℃になりました。熊本県くまもとけんでは、40℃以上いじょうの「酷暑こくしょ日び」に初はじめてなりました。
県けんは、車くるまの中なかで避難ひなんしていた女性じょせいが、7月がつ30日にちに亡なくなったと発表はっぴょうしました。熱中症ねっちゅうしょうかもしれません。女性じょせいは70歳さいぐらいです。車くるまにガソリンはありませんでした。ガソリンがないとエアコンを使つかうことができません。
4日よっかも暑あつくなりそうです。気象庁きしょうちょうは、熱中症ねっちゅうしょうにならないように気きをつけてくださいと言いっています。
昼間ひるまは家いえの片付かたづけなどのために外そとにいる時間じかんを減へらしましょう。暑あつい時間じかんは、できるだけ涼すずしい所ところにいてください。片付かたづけなどは、少すこしでも涼すずしい時間じかんにしてほしい、と専門家せんもんかは話はなしています。

県けんは、避難所ひなんじょにいる人ひとたちに、安全あんぜんな場所ばしょにあるホテルなどに、もう一度いちど避難ひなんしてほしいと考かんがえています。「2次じ避難ひなん」と言いいます。お風呂ふろに入はいったり、ベッドで寝ねたりして、休やすむことができます。
3みっ日かから、宇土市うとし、宇城市うきし、八代市やつしろし、そして氷川町ひかわちょうで、「2次じ避難ひなん」したい人ひとの受うけ付つけが始はじまりました。県けんは、90以上いじょうのホテルなどを準備じゅんびしています。

小笠原諸島おがさわらしょとうでは、3みっ日かから5日いつかに、波なみが高たかくなったり、風かぜが強つよくなったりしそうです。
4日よっかは、とても強つよい風かぜが吹ふきそうです。何なにかにつかまらないと立たっていられないほどの風かぜです。
雷かみなりが鳴なって、激はげしい雨あめが降ふるかもしれません。
大雨おおあめで山やまが崩くずれるかもしれません。
台風たいふう13号ごうは西にしに進すすんで、6日むいかには、沖縄県おきなわけんや鹿児島県かごしまけんの奄美地方あまみちほうの近ちかくに行いきそうです。

4️⃣ 羽田空港はねだくうこう　「飛行機ひこうきに乗のる30分ぷん前まえに荷物にもつを預あずけて」

羽田空港はねだくうこうでは、今いま、飛行機ひこうきに乗のる人ひとは、出発しゅっぱつの20分ぷん前まえまでに荷物にもつを預あずけます。
9月がつからは、出発しゅっぱつの30分ぷん前まえまでになります。今いままでより10分ぷん早はやいです。
2025年ねん、羽田空港はねだくうこうで飛行機ひこうきに乗のったり降おりたりした人ひとは、9000万まん人にん以上いじょういました。
飛行機ひこうきに乗のる人ひとの荷物にもつを運はこぶのに時間じかんがかかって、出発しゅっぱつが遅おくれることが増ふえています。
50歳さいぐらいの女性じょせいは、「最近さいきんはよく遅おくれているなと思おもっていました。少すこし早はやく空港くうこうに来きます」と話はなしていました。
