気象庁きしょうちょうと国土交通省こくどこうつうしょうは、午後ごご6時じ20分ぷん、庄内しょうない川がわにレベル5の「氾濫はんらん特別警報とくべつけいほう」を出だしました。レベル5はいちばん危険きけんなときに出だします。
庄内しょうない川がわでは、すでに水みずが川かわの外そとに出でている所ところがあるかもしれません。
避難所ひなんじょに行いくのが難むずかしかったり危あぶなかったりする場合ばあいは、建物たてものの2階かい以上いじょうの高たかい場所ばしょに行いくなど安全あんぜんをいちばんに考かんがえてください。

台風たいふうのまわりでは、とても強つよい風かぜが吹ふいています。
「線状降水帯せんじょうこうすいたい」ができて、雨あめが同おなじ場所ばしょで長ながい時間じかんたくさん降ふるかもしれません。
気象庁きしょうちょうは「線状降水帯せんじょうこうすいたいに気きをつけてください。急きゅうに雨あめがたくさん降ふって危険きけんになるかもしれません」と言いっています。
この台風たいふうの東ひがしの方ほうには、台風たいふう15号ごうがあります。来週らいしゅう、東北地方とうほくちほうや関東地方かんとうちほうの近ちかくに来くるかもしれません。新あたらしい情報じょうほうに気きをつけてください。

ホームページによると、できるだけ子こどもを1人ひとりにしないでください。
心配しんぱいしていると思おもったら、体からだをやさしく抱だいてあげましょう。
子こどもの話はなしをよく聞きいて、質問しつもんにはわかりやすく答こたえましょう。
子こどもは怖こわい経験けいけんをすると、いつもできることができなくなるかもしれません。でも、叱しからないでください。
