アメリカのトランプ大統領だいとうりょうは、戦たたかいを止とめるのは日本にっぽんの時間じかんの23日にちの午前ごぜんまでだと言いっていました。

2️⃣ 北海道ほっかいどうの小学校しょうがっこう　地震じしんや津波つなみのときにどうしたらいいかを話はなした

20日はつかの地震じしんのあと、国くには北海道ほっかいどうや東北地方とうほくちほうなど182の市しや町まち、村むらに、特別とくべつな情報じょうほうを出だして、気きをつけるように言いっています。
北海道浦河町ほっかいどううらかわちょうの小学校しょうがっこうでは、地震じしんや津波つなみが来きたときにどうしたらいいか、先生せんせいが子こどもたちに話はなしました。
津波つなみが来きたら、すぐに逃にげることが大切たいせつです。
先生せんせいは、いつもは教室きょうしつの外そとに置おいている帽子ぼうしや上着うわぎなどを、自分じぶんの近ちかくに置おくように言いいました。そして教室きょうしつに水みずと体からだを温あたためるカイロを用意よういしたので、持もって逃にげましょうと言いいました。
6年生ねんせいの男おとこの子こは「地震じしんが来きたら、すぐ山やまに逃にげるようにします」と話はなしていました。

3️⃣ 東京とうきょうの遊園地ゆうえんちで事故じこ　働はたらいていた女性じょせいが亡なくなった

21日にち、東京とうきょうの文京区ぶんきょうくにある遊園地ゆうえんちで事故じこがありました。働はたらいていた24歳さいの女性じょせいが亡なくなりました。
女性じょせいは、「フライングバルーン」という乗のり物ものを6人にんでチェックしていました。
この乗のり物ものは、客きゃくが乗のるいすが柱はしらのまわりにあって、高たかさ10mまで上あがります。
女性じょせいがチェックしていたとき、上うえで止とまっていたいすが急きゅうに落おちてきました。
女性じょせいは、いすと柱はしらの間あいだで動うごくことができなくなって、亡なくなりました。
警察けいさつによると、この乗のり物ものは機械きかいを使つかって動うごかしますが、事故じこが起おこったときは誰だれも動うごかしていなかったようです。
警察けいさつで、事故じこの原因げんいんを調しらべています。

4️⃣ 「はしか」に気きをつけて　授業じゅぎょうが休やすみになった学校がっこうもある

「はしか」という病気びょうきになる人ひとが増ふえています。
はしかのウイルスはうつりやすくて、熱ねつやせきが出でます。ひどくなると亡なくなることもあります。
東京とうきょうの新宿区しんじゅくくにある小学校しょうがっこうで、子こどもたちや先生せんせいなど18人にんがはしかになりました。
学校がっこうは今月こんげつ20日はつかから24日にじゅうよっかまで、はしかになった人ひとが多おおい学年がくねんを休やすみにしました。
専門家せんもんかは「これから休やすみが続つづいてたくさんの人ひとが出でかけます。ワクチンを受うけるなど、はしかにならないように気きをつけてください」と話はなしています。
