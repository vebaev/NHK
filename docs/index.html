1️⃣ 台風たいふう9号ごう　沖縄県おきなわけんは強つよい風かぜと高たかい波なみなどに気きをつけて

気象庁きしょうちょうによると、台風たいふう9号ごうが沖縄県おきなわけんに向むかっています。
11日にちの夜よるまで宮古島みやこじまや石垣島いしがきじまなどで、とても強つよい風かぜが吹ふきそうです。家いえが倒たおれるぐらいの強つよい風かぜです。
雨あめも、たくさん降ふりそうです。海うみでは、高たかい波なみにも気きをつけてください。
10日とおかも、たくさんの場所ばしょでとても暑あつくなりました。
特とくに九州きゅうしゅうで暑あつくなりました。福岡県ふくおかけんの太宰府市だざいふしで37.8℃、大分県おおいたけんの日田市ひたしで37.1℃になりました。東京とうきょうや大阪おおさかでも30℃以上いじょうになりました。
11日にちも暑あつくなりそうです。エアコンを使つかって、水みずを十分じゅうぶんにとってください。

2️⃣ 日本にっぽんで生産せいさんしたお茶ちゃだけを「日本茶にほんちゃ」と呼よぶことを決きめた

国くには、日本にっぽんで生産せいさんしたお茶ちゃだけを「日本茶にほんちゃ」と呼よぶことを決きめました。
10日とおかは農林水産省のうりんすいさんしょうで、日本茶にほんちゃを生産せいさんするグループの代表だいひょうに、「登録とうろく証しょう」を渡わたす式しきがありました。　
外国がいこくでは、抹茶まっちゃが人気にんきになっています。去年きょねん、日本にっぽんが外国がいこくに輸出ゆしゅつしたお茶ちゃの金額きんがくは721億おく円えんでした。前まえの年としの2倍ばいに増ふえて、今いままででいちばん多おおくなりました。
しかし、外国がいこくで生産せいさんしたのに日本にっぽんのまちの名前なまえを使つかったお茶ちゃがたくさんあります。
お茶ちゃを生産せいさんする団体だんたいの人ひとは、日本にっぽんで生産せいさんしたお茶ちゃだとわかるようにしたいと話はなしています。

3️⃣ 杉並区すぎなみくの区長くちょう　「家族かぞくとの時間じかんを大切たいせつにするため3週間しゅうかん休やすむ」

東京とうきょう、杉並区すぎなみくの岸本きしもと聡子さとこ区長くちょうは、7月がつ13日にちから8月がつ4日よっかまで3週間しゅうかん以上いじょう、仕事しごとを休やすむと言いいました。
遠とおい所ところに住すんでいる息子むすことの時間じかんを大切たいせつにしたいと話はなしています。
岸本きしもと区長くちょうは、自分じぶんが休やすんだら、職員しょくいんたちも休やすみやすくなると考かんがえています。
休やすみの間あいだは、週しゅうに1回かい、オンラインで会議かいぎをする予定よていです。災害さいがいが起おこった場合ばあいは、岸本きしもと区長くちょうが区役所くやくしょに行いって仕事しごとをします。

4️⃣ 山梨県やまなしけん　「桃ももの食たべ放題ほうだい」のイベントが始はじまった

桃ももがおいしい季節きせつになりました。　
山梨県南やまなしけんみなみアルプス市しで、「桃ももの食たべ放題ほうだい」のイベントが始はじまりました。30分ぷんで、何個なんこでも桃ももを食たべることができます。　
9日ここのかは、始はじまる前まえから100人にんぐらいが集あつまっていました。　集あつまった人ひとたちは、小ちいさいプールから　桃ももを取とって、食たべていました。　
長野県ながのけんから来きた女性じょせいは、「おいしいです。4個こ食たべて、おなかがいっぱいになりましたが、10個こ食たべたいです」と話はなしていました。このイベントは、13日にちと14日じゅうよっかも行おこないます。
